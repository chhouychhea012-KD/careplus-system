Setup steps

  1. Create a bot with @BotFather (/newbot).
  2. Host this server at a public HTTPS address.
  3. In BotFather (/newapp or Bot Settings → Configure Mini App), set the Mini App URL to your public address followed by /tg.
  4. Set the bot token environment variable and integration mode, then restart the server.
  5. Enter the bot username and public URL here, then print the posters.
